# ⚔️ RULES

### 01 — Think Before Looking

Don't immediately search for the solution.

### 02 — Understand Before Coding

Know what the problem is asking.

### 03 — Don't Fear Brute Force

A correct brute-force solution is the starting point.

### 04 — Learn From TLE

If a solution fails because of complexity, understand **why**.

### 05 — Record Mistakes

Every important mistake becomes revision material.

### 06 — Don't Count a Problem as Learned Until I Can Explain It

Accepted code ≠ understood problem.

### 07 — No Zero Days

Small progress is still progress.
